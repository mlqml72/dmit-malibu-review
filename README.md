## 三网 CN2 GIA：Malibu 的核心竞争力

很多人分不清这些线路名词，简单解释一下：

**CN2 GIA（Global Internet Access）** 是中国电信旗下 AS4809 骨干网的优质出口线路，特点是：
- 延迟低（洛杉矶到国内通常 150ms 以内）
- 丢包少（晚高峰也能保持稳定）
- 绕过拥堵节点直连

Malibu 套餐的线路配置是：

- **电信**：CN2 GIA 双向优化（去程 + 回程均走 AS4809）
- **联通**：CN2 直连出口
- **移动**：CMIN2（AS58807）优化，移动用户体验同样不差

这就是所谓的"**三网 CN2 GIA 回程**"——三大运营商的用户访问你服务器时，走的都是优化线路，而不是绕一圈普通公网。

> 想验证？测试 IP：`154.17.2.14`（洛杉矶 LAX Pro 系列）。找个国内网络 ping 一下，延迟通常在 130–160ms 之间，晚高峰也不会抖成翔。

对比同价位的普通美国 VPS（走 AS4837 或普通 transit），晚高峰延迟可能飙到 300ms+ 并伴随严重丢包——差距就在这里。

## 性能实测：硬件跑分表现如何？

AN4 代表 DMIT 第四代硬件平台，搭载 **AMD EPYC 9654** 处理器，这颗 CPU 的单核性能在 VPS 场景里属于第一梯队。

根据社区实测数据（YABS 跑分）：

- **磁盘 I/O**：顺序读写普遍在 800MB/s–1.2GB/s 之间，SSD 性能扎实
- **网络速度**：上下行均可跑满 1Gbps，国内三网实测下载速度在晚高峰仍能维持 50–200MB/s
- **内存**：1GB 对于建站、代理、轻量应用足够，跑大型数据库会比较吃力
- **流媒体解锁**：洛杉矶 IP 支持 Netflix、Disney+、HBO Max 等主流平台解锁

一个典型的使用场景：用 Malibu 做反代或中转节点，国内用户访问速度相当稳定，尤其移动用户走 CMIN2 的体验比很多"移动优化"产品还好。
